# 夜行电影海报

围绕一个清楚主体，用夜景纵深、可信光线和独立标题区制作或编辑电影感海报。列车、夜站和蓝橙配色只是案例选择，具体场景随本次内容设计。

提供主题、确认的文案、尺寸及必要的授权参考，将完整目录交给支持 Skill 的助手，使用 `$produce-night-cinema-poster`。入口与制作要求见 [SKILL.md](SKILL.md)。已有稿请附当前成图与可编辑源，说明保留与修改范围。

例如：用这个 Skill 为【活动或产品】制作夜行电影感海报，让【主体】在夜景中清楚可辨，给【完整标题】留出独立空间，并核对手机缩略图。

运行时需要可用的图像生成或编辑工具、独立文字排版和导出能力，以及获授权的字体与输入素材。本仓库不附服务账号或原始个人素材。按请求交付实际海报与必要的可编辑排版源。

## 实际案例：AI Native 新时代列车（完整海报）

![AI Native 新时代列车完整海报](examples/poster.png)

- **实际输入**：以“AI Native 新时代列车”为主题，将品牌、教程与 Skill 分类、会员权益、资历及用户确认的服务与联系文案编排为完整宣传海报。
- **视觉与版面**：夜站透视、冷暖光与列车轮廓建立电影氛围；信息区延续夜景色盘，以稳定对比、分隔线和暖色重点保持完整阅读顺序。
- **实际输出与检查**：此处展示1080×1440的整张定稿，主视觉、标题、详情、服务条件与行动入口均包含在同一张图中。已查看完整成图，核对标题与关键主体的间隔、各组信息归属以及底部行动区的完整性。案例中的具体文案、人物、数量和模块只对应本次任务，后续按实际需求重排。
